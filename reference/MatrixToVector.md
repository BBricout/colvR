# MatrixToVector

Convert a numeric matrix to a numeric vector (column-major order).
Implemented in C++ via Rcpp/Armadillo.

## Usage

``` r
MatrixToVector(matrix)
```

## Arguments

- matrix:

  Numeric matrix (n x p).

## Value

Numeric vector of length n\*p.
